-----------------------------------------------------------------------
HOW THE FAULT WAS INJECTED
-----------------------------------------------------------------------
At instruction #500000 that has a replica assigned, we flip bit 0 of
oirResult using XOR with 0x1. This simulates a single bit-flip
transient fault occurring in a register value mid-execution.

The comparator at commit then compares oirResult against oirResultCopy
which was saved at issue time before any fault could occur.
